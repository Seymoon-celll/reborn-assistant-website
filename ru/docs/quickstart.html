🚀 Быстрый Старт

Установите и настройте Reborn Assistant за несколько минут

Требования

🌐
Совместимый браузер: Google Chrome, Microsoft Edge, Brave или любой браузер на основе Chromium
🔧
Аккаунт Google: Требуется только для Premium-аутентификации (необязательно для бесплатной версии)
🎮
Совместимый сайт: Совместим со стандартными веб-сайтами

Установка

1
Посетите Chrome Web Store

Перейдите на страницу Reborn Assistant в Chrome Web Store и нажмите «Добавить в Chrome».

💡 Совместим с Google Chrome, Microsoft Edge, Brave и любым браузером на основе Chromium.

2
Подтвердите установку

Нажмите «Добавить расширение» в окне подтверждения. Расширение устанавливается автоматически.

3
Закрепите расширение

Нажмите на иконку пазла 🧩 на панели инструментов браузера и закрепите Reborn Assistant для быстрого доступа.

4
Вход (необязательно для Premium)

• Нажмите на иконку Reborn на панели инструментов
• Для Premium: Войдите через аккаунт Google
• Для бесплатного: Используйте напрямую без входа

✅ Установка выполнена успешно! Иконка Reborn становится зелёной, когда расширение активно. Теперь вы можете настроить функции.

Начальная настройка

БЕСПЛАТНАЯ Версия

Функции, доступные без входа:

• Автоматическое действие типа 1 (только HP)
• 6 визуальных тем
• Поддержка 15 языков

Настройка автоматического действия типа 1

1. Откройте панель Reborn (нажмите на иконку)
2. Настройте таймер действия HP (по умолчанию: 2с)
3. Действие активируется автоматически
4. Вход не требуется

PREMIUM Версия 💎

Дополнительные функции (требуется вход через Google):

• Автоматический макрос триггера 1 (настраиваемый таймер + горячая клавиша)
• Автоматический макрос триггера 2 (настраиваемый таймер + горячая клавиша)
• Горячие клавиши (CTRL+A / CTRL+O)
• Автоматическая ротация последовательностей (F2 → 1-9 → 0 → F1)
• 3 настраиваемых макроса с последовательностями клавиш
• Автоматическая система периодического макроса (вызов + сохранение каждые 15с)

Настройка Premium

Автоматические последовательности:
• Активируйте «Ротацию последовательностей» на панели
• Настройте интервал между циклами (по умолчанию: 5 мин)
• Настройте задержку между каждой клавишей (по умолчанию: 1с)

Макросы:
• Активируйте Макрос 1, 2 или 3
• Задайте последовательность клавиш (напр. 1,2,3,4)
• Настройте интервал повторения

Периодический макрос:
• Активируйте переключатель «Периодический макрос»
• Система автоматически вызывает периодический макрос каждые 15с
• Автоматическое сохранение после вызова

⚠️ Важное примечание Premium-функции (Макросы триггеров 1 и 2, Автоматические последовательности, Автоматический периодический макрос, 3 настраиваемых макроса) требуют действующей Premium-лицензии и входа через Google. Без лицензии доступен только базовый макрос.

Горячие клавиши

CTRL + A: Запустить автоматизацию
CTRL + O: Остановить автоматизацию
