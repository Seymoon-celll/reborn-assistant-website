🎨 Интерфейс & Персонализация

Настройте Reborn Assistant под свои предпочтения

Визуальные темы

Reborn Assistant предлагает 6 тем для персонализации интерфейса:

MMO Gold
Cyber Blue
Neon Purple
Fire Red
Dark Mode
White Mode

Смена темы

1. Откройте панель Reborn
2. Нажмите на вкладку "⚙️ НАСТРОЙКИ"
3. Выберите тему в выпадающем меню
4. Изменение мгновенное

Горячие клавиши

Reborn Assistant включает глобальные горячие клавиши для быстрого управления:

Системные горячие клавиши

  • CTRL + A: Запустить автоматизацию
  • CTRL + O: Остановить автоматизацию

Настраиваемые горячие клавиши

Вы можете настроить клавиши для:

  • Действий типа 1 и 2
  • Макросов (последовательности клавиш)
  • Периодического макроса

Параметры отображения

Положение панели

Панель Reborn можно перетаскивать:

  1. Нажмите на заголовок панели
  2. Удерживайте и перетащите
  3. Отпустите в нужном месте
  4. Положение сохраняется автоматически

Прозрачность панели

Настройте прозрачность, чтобы не мешать навигации при управлении статистикой.

Журнал активности

Журнал отображает в реальном времени все выполненные действия:

  • Активация/деактивация систем
  • Использование зелий
  • Выполнение макросов и последовательностей
  • Вызовы периодического макроса
  • Возможные ошибки

Сохранение настроек

Все настройки сохраняются автоматически локально:

  • Выбранная тема
  • Язык интерфейса
  • Пороги активации
  • Назначенные клавиши
  • Конфигурация макросов
  • Положение панели

Сохраняются между сеансами, даже после закрытия браузера.
