🎨 Oberfläche & Anpassung

Passen Sie Reborn Assistant nach Ihren Wünschen an

Visuelle Themes

Reborn Assistant bietet 6 Themes zur Anpassung des Erscheinungsbilds:

MMO Gold
Cyber Blue
Neon Purple
Fire Red
Dark Mode
White Mode

Theme wechseln

1. Öffnen Sie das Reborn-Panel
2. Klicken Sie auf „⚙️ EINSTELLUNGEN”
3. Wählen Sie Ihr Theme im Dropdown-Menü
4. Die Änderung ist sofort wirksam

Sprache wechseln

1. Öffnen Sie das Reborn-Panel
2. Klicken Sie auf „⚙️ EINSTELLUNGEN”
3. Wählen Sie Ihre Sprache im Dropdown-Menü
4. Die gesamte Oberfläche wird sofort übersetzt

Tastenkombinationen

Reborn Assistant beinhaltet globale Tastenkombinationen für schnelle Steuerung:

System-Tastenkombinationen

  • STRG + A: Automatisierung starten
  • STRG + O: Automatisierung stoppen

Anpassbare Tasten

Sie können Tasten konfigurieren für:

  • Aktionen Typ 1 und 2
  • Makros (Tastensequenzen)
  • Periodisches Makro

Anzeigeoptionen

Panel-Position

Das Reborn-Panel ist verschiebbar:

  1. Klicken Sie auf den Panel-Header
  2. Halten Sie die Schaltfläche gedrückt und ziehen
  3. An der gewünschten Position loslassen
  4. Die Position wird automatisch gespeichert

Panel-Transparenz

Passen Sie die Transparenz an, damit das Panel Ihre Navigation nicht stört.

Aktivitätsprotokoll

Das Protokoll zeigt in Echtzeit alle durchgeführten Aktionen:

  • Aktivierung/Deaktivierung von Systemen
  • Verwendung von Tränken
  • Ausführung von Makros und Sequenzen
  • Aufrufe des periodischen Makros
  • Mögliche Fehler

Parametergespeicherung

Alle Ihre Konfigurationen werden automatisch lokal gespeichert:

  • Ausgewähltes Theme
  • Oberflächensprache
  • Auslöserschwellen
  • Zugewiesene Tasten
  • Makro-Konfiguration
  • Panel-Position

Diese bleiben zwischen Sitzungen erhalten, auch nach dem Schließen des Browsers.
