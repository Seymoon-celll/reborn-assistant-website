常见问题解决方案和常见问题解答

安装问题

❌ 扩展程序未出现在工具栏中

解决方案：
1. 确认扩展程序从 Chrome 网上应用店安装
2. 固定扩展程序：点击工具栏中的拼图图标 🧩，固定 Reborn Assistant
3. 重启浏览器
4. 如问题持续，从 Chrome 网上应用店卸载并重新安装扩展程序

连接问题

❌「连接失败」或「无效许可证」

可能原因：
• 不稳定的网络连接
• Google Cloud 服务器临时不可用
• 许可证已过期或已取消

解决方案：
1. 检查网络连接
2. 从 Google 退出并重新登录
3. 在 Stripe 门户检查许可证状态
4. 如问题持续，联系支持

❌ 面板显示「FREE」，但我有高级版

1. 退出 Google 账户
2. 完全关闭浏览器
3. 重新打开并登录
4. 如问题持续，确认您使用正确的 Google 账户登录（购买时使用的）

功能问题

❌ 类型 1/2 动作未激活

⚠️ 重要
类型 1 和 2 动作是高级专属功能。只有类型 1 自动动作（HP）在免费版中可用。
如果您有 Premium：
1. 自动化正在运行吗？CTRL+A
2. 触发开关是否已启用？（绿色指示灯「ON」）
3. 配置的按键是否正确？

❌ 序列/宏/周期性宏/快捷键不起作用

⚠️ 重要
键盘快捷键、序列、宏和周期性宏是高级专属功能。在免费版中，只有类型 1 自动动作（HP）可用。
如果您有高级版：
1. 确认高级许可证处于活跃状态（面板中的 💎 图标）
2. 相应开关已激活吗？
3. 检查配置的间隔和延迟

❌ 自动化自己停止了

可能的原因：
• 与 Google Cloud 的连接中断
• 检测到 DevTools
• 页面 URL 已更改

解决方案：
1. 使用 CTRL+A 重新启动自动化（Premium）或通过面板
2. 重新加载相关页面
3. 检查您的互联网连接
4. 如果您是 Premium 用户，请不要打开 DevTools

优化与性能

💡 扩展程序消耗太多资源

建议：
• 增加宏和序列的间隔（动作越少 = CPU 使用越少）
• 停用不需要的系统
• 关闭不必要的标签页
• 使用优化的浏览器（Brave、Edge 比 Chrome 更轻量）

💡 如何优化我的设置？

推荐设置：
• 序列间隔：5 到 25 分钟（取决于序列持续时间）
• 键间延迟：1 到 2 秒（防止错误）
• 宏：根据使用情况设置 10 到 30 秒间隔

常见问题解答

❓ 我可以在多个浏览器上使用 Reborn 吗？

是的，但需要在每个浏览器上安装扩展程序。只要使用同一个 Google 账户登录，高级许可证可在所有设备上使用（最多 1 个同时连接）。

❓ 我的数据会被保存吗？

所有设置（键、宏、主题、语言）都本地存储在您的浏览器中。它们在会话之间保留。但是，卸载扩展程序时，这些数据将丢失。

❓ Reborn 会导致封号吗？

使用自动化工具可能违反某些服务的服务条款。您独自负责如何使用 Reborn。使用此工具前请查看服务的使用条款。

❓ 如何取消高级订阅？

您可以随时从 Stripe 管理门户（购买后收到的邮件中的链接）取消。取消将在当前期间结束时生效。无取消费用。

❓ 如果服务关闭，终身方案会怎样？

终身方案保证在服务活跃期间的访问。安装后，扩展程序在本地运行。只有许可证验证需要网络连接。
