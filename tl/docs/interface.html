🎨 Interface at Personalisasyon

I-customize ang Reborn Assistant ayon sa iyong mga kagustuhan

Mga Visual na Tema

Nag-aalok ang Reborn Assistant ng 6 na tema para i-personalize ang hitsura ng iyong interface:

MMO Gold
Cyber Blue
Neon Purple
Fire Red
Dark Mode
White Mode

Palitan ang Tema

1. Buksan ang Reborn panel
2. I-click ang tab na "⚙️ Settings"
3. Piliin ang tema mula sa dropdown menu
4. Agad na magkakabisa ang mga pagbabago

Mga Keyboard Shortcut

Ang Reborn Assistant ay may kasamang global shortcuts para sa mabilis na kontrol:

Mga System Shortcut

  • CTRL + A: Simulan ang automation
  • CTRL + O: Itigil ang automation

Mga Custom Shortcut

Maaari kang mag-assign ng key para sa:

  • Type 1 at 2 na aksyon
  • Mga Macro (key sequences)
  • Periodic Macro

Mga Opsyon sa Display

Posisyon ng Panel

Maaaring i-drag ang Reborn panel:

  • I-click ang header ng panel
  • Hawakan at i-drag
  • Ilagay sa nais na posisyon
  • Awtomatikong ise-save ang posisyon

Opacity ng Panel

Ayusin ang transparency para hindi maabala ang pag-navigate habang pinamamahalaan ang iyong stats.

Activity Log

Ipinapakita ng log ang lahat ng aksyon na ginawa sa real time:

  • Pag-activate/deactivate ng system
  • Paggamit ng potion
  • Pag-execute ng macros at sequences
  • Pag-call ng periodic macro
  • Mga posibleng error

Pag-save ng mga Setting

Lahat ng mga setting ay awtomatikong nase-save nang lokal:

  • Napiling tema
  • Wika ng interface
  • Mga activation threshold
  • Mga assigned na key
  • Macro configurations
  • Posisyon ng panel

Nananatili sa pagitan ng mga session kahit pagkatapos isara ang browser.
