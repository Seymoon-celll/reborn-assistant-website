🛡️ Auto Sequence Rotation

PREMIUM

Ang rotation system ay awtomatikong nagpapanatili ng lahat ng sequences sa pamamagitan ng pagpindot sa predefined key sequence sa regular na agwat.

Key Sequence

Ang rotation ay laging sumusunod sa fixed na pagkakasunod na ito:

F2→ 1→ 2→ 3→ 4→ 5→ 6→ 7→ 8→ 9→ 0→ F1

Configuration

Agwat sa pagitan ng mga cycle
Oras ng paghihintay bago ulitin ang buong sequence. Default: 5 minuto. Ayusin ayon sa tagal ng pinakamaikling sequence.
Delay sa pagitan ng mga key
Oras ng paghihintay sa pagitan ng bawat key sa sequence. Default: 1 segundo. Ayusin ayon sa bilis ng serbisyo (animations, cooldowns...).
💡 Halimbawa ng Paggamit

Scenario: Ang sequence ay tumatagal ng 5 minuto at mayroon kang 8 sequences sa mga key 1-8.

Configuration:

  • Agwat: 5 minuto
  • Delay: 1 segundo
  • Ang extension ay pipindutin ang F2, 1, 2, 3, 4, 5, 6, 7, 8, 9, 0, F1 kada 5 minuto
  • 13 key total, 1 segundo sa pagitan ng bawat isa = ~13 segundo bawat cycle

⚙️ Mga Custom Macro

PREMIUM

Gumawa ng hanggang 3 independent na macros na may sariling key sequences. Perpekto para sa pag-automate ng mga paulit-ulit na gawain, regular na combos, o skill rotations.

Paano Ito Gumagana

Ang bawat macro ay nagpapatakbo ng key sequence sa regular na agwat, nang independyente sa iba pang mga system.

Configuration

Key Sequence
Tukuyin ang mga key na pipindutin sa pagkakasunod, na pinaghihiwalay ng kuwit. Hal: 1,2,3,4 o q,w,e,r,f
Repetition Interval
Oras ng paghihintay bago ulitin ang sequence. I-set ayon sa iyong pangangailangan (sa segundo o minuto).
Delay sa pagitan ng mga key
Oras ng paghihintay sa pagitan ng bawat key sa sequence (kadalasan 0.5 hanggang 2 segundo).
💡 Mga Halimbawa ng Paggamit

Macro 1 – Repetitive Automation:

  • Sequence: 1,2,3,space
  • Agwat: 10 segundo
  • Paggamit: Pangunahing attack rotation sa loop

Macro 2 – Skill Combo:

  • Sequence: q,w,e,r
  • Agwat: 30 segundo
  • Paggamit: Optimal DPS rotation

Macro 3 – Auto Support:

  • Sequence: f,g,h
  • Agwat: 15 segundo
  • Paggamit: Group sequence o periodic action

🐉 Periodic Macro

PREMIUM

Awtomatikong nagpapatakbo ang system na ito ng periodic action bawat 15 segundo. Perpekto para sa mga paulit-ulit na gawain na kailangang i-activate nang regular.

Paano Ito Gumagana

Awtomatikong isinasagawa ng system ang sequence na ito bawat 15 segundo:

  1. Pag-call ng periodic macro (configurable key, default §)
  2. Maghintay ng 500ms
  3. Awtomatikong pag-save ng periodic macro

Configuration

Call Key
Ang key na nag-a-activate ng periodic macro. Default: §. Baguhin ayon sa iyong configuration.
Agwat (fixed)
Laging gumagamit ang system ng fixed na 15-segundo na agwat. Hindi maaaring i-configure.
💡 Mga Use Case

Sa ilang serbisyo, kailangan mong regular na tawagan ang periodic macro para makakuha ng mga item, mag-trigger ng mga temporary sequence, o makakuha ng experience. Ganap na inaautomate ng system na ito ang prosesong ito.

⚠️ Mahalaga

  • Tiyaking ang configured na key ay tumutugma sa call key
  • Awtomatikong nase-save ang periodic macro pagkatapos ng bawat call
  • Gumagana nang parallel sa iba pang mga system (sequences, macros, actions)

Mga Tip sa Pag-optimize

🎯 Pagsasama ng mga System

Lahat ng premium na feature ay gumagana nang sabay-sabay. Maaari kang:

  • Pagsamahin ang Auto Sequences + 3 Macros + Periodic Macro nang sabay
  • Ang Trigger Actions 1 at 2 ay laging gumagana nang parallel
  • Ang bawat system ay may sariling independent na timer

⚡ Performance

  • Habang mas maraming system ang inaktibo, mas maraming resources ang kino-consume ng extension
  • Ayusin ang mga agwat para maiwasan ang masyadong madalas na mga aksyon
  • Subaybayan ang activity log para matiyak ang tamang operasyon

🔑 Seguridad

  • Ang premium license ay validated sa real time
  • Kapag naputol ang koneksyon, nade-deactivate ang mga premium na feature
  • Mag-login ulit para muling i-activate ang lahat ng feature
