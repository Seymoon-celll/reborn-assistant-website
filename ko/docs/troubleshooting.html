🔧 문제 해결

일반적인 문제 해결책과 자주 묻는 질문

설치 문제

❌ 확장 프로그램이 도구 모음에 나타나지 않음

해결책:
1. 확장 프로그램이 Chrome 웹 스토어에서 설치되었는지 확인
2. 확장 프로그램 고정: 도구 모음의 퍼즐 아이콘 🧩을 클릭하고 Reborn Assistant 고정
3. 브라우저 재시작
4. 문제가 지속되면 Chrome 웹 스토어에서 확장 프로그램을 제거하고 다시 설치

연결 문제

❌ "연결 실패" 또는 "유효하지 않은 라이선스"

가능한 원인:
• 불안정한 인터넷 연결
• Google Cloud 서버 일시적 사용 불가
• 만료되거나 취소된 라이선스

해결책:
1. 인터넷 연결 확인
2. Google에서 로그아웃 후 다시 로그인
3. Stripe 포털에서 라이선스 상태 확인
4. 문제가 지속되면 지원팀에 연락

❌ 프리미엄인데 패널에 "FREE"가 표시됨

1. Google 계정에서 로그아웃
2. 브라우저 완전히 닫기
3. 다시 열고 로그인
4. 문제가 지속되면 올바른 Google 계정(구매 시 사용한 것)으로 로그인했는지 확인

작동 문제

❌ 타입 1/2 액션이 활성화되지 않음

⚠️ 중요
타입 1과 2 액션은 프리미엄 전용 기능입니다. 타입 1 자동 액션(HP)만 무료 버전에서 사용 가능합니다.
Premium을 사용 중인 경우:
1. 자동화가 실행 중입니까? CTRL+A
2. 트리거 토글이 활성화되어 있습니까? (녹색 표시 「ON」)
3. 구성된 키가 올바릅니까?

❌ 시퀀스/매크로/주기적 매크로/단축키가 작동하지 않음

⚠️ 중요
키보드 단축키, 시퀀스, 매크로, 주기적 매크로는 프리미엄 전용 기능입니다. 무료 버전에서는 타입 1 자동 액션(HP)만 사용 가능합니다.
프리미엄이 있는 경우:
1. 프리미엄 라이선스가 활성 상태인지 확인(패널의 💎 아이콘)
2. 해당 스위치가 활성화되어 있나요?
3. 설정된 간격과 지연 확인

❌ 자동화가 저절로 멈춥니다

가능한 원인:
• Google Cloud 연결 끊김
• DevTools 감지
• 페이지 URL 변경

해결 방법:
1. CTRL+A로 자동화 재시작 (Premium) 또는 패널을 통해
2. 해당 페이지 다시 로드
3. 인터넷 연결 확인
4. Premium 사용 시 DevTools를 열지 마세요

최적화 & 성능

💡 확장 프로그램이 리소스를 너무 많이 사용합니다

권장 사항:
• 매크로와 시퀀스의 간격을 늘리세요(액션이 적을수록 CPU 사용 감소)
• 필요하지 않은 시스템 비활성화
• 불필요한 탭 닫기
• 최적화된 브라우저 사용(Brave, Edge는 Chrome보다 가볍습니다)

💡 설정을 최적화하는 방법은?

권장 설정:
• 시퀀스 간격: 5~25분(시퀀스 지속 시간에 따라)
• 키 사이 지연: 1~2초(오류 방지)
• 매크로: 사용에 따라 10~30초 간격

자주 묻는 질문

❓ 여러 브라우저에서 Reborn을 사용할 수 있나요?

네, 하지만 각 브라우저에 확장 프로그램을 설치해야 합니다. 동일한 Google 계정으로 로그인하는 한 프리미엄 라이선스는 모든 기기에서 작동합니다(최대 1개의 동시 연결).

❓ 내 데이터가 저장되나요?

모든 설정(키, 매크로, 테마, 언어)은 브라우저에 로컬로 저장됩니다. 세션 간에 유지됩니다. 그러나 확장 프로그램을 제거하면 이 데이터가 손실됩니다.

❓ Reborn이 밴을 유발할 수 있나요?

자동화 도구 사용은 일부 서비스의 서비스 약관을 위반할 수 있습니다. Reborn 사용 방법에 대해서는 귀하만이 책임을 집니다. 이 도구를 사용하기 전에 서비스의 이용 약관을 확인하세요.

❓ 프리미엄 구독을 취소하는 방법은?

Stripe 관리 포털(결제 후 이메일로 받은 링크)에서 언제든지 취소할 수 있습니다. 취소는 현재 기간이 끝날 때 적용됩니다. 취소 수수료 없음.

❓ 서비스가 종료되면 평생 플랜은 어떻게 되나요?

평생 플랜은 서비스가 활성 상태인 한 액세스를 보장합니다. 설치 후 확장 프로그램은 로컬로 작동합니다. 라이선스 확인만 인터넷 연결이 필요합니다.
