선호도에 맞게 Reborn Assistant 사용자 정의

시각적 테마

Reborn Assistant는 인터페이스 외관을 개인화하기 위한 6가지 테마를 제공합니다:

MMO Gold
Cyber Blue
Neon Purple
Fire Red
Dark Mode
White Mode

테마 변경

1. Reborn 패널 열기
2. "⚙️ 설정" 탭 클릭
3. 드롭다운 메뉴에서 테마 선택
4. 변경 사항이 즉시 적용됨

키보드 단축키

Reborn Assistant에는 빠른 제어를 위한 전역 단축키가 포함되어 있습니다:

시스템 단축키

  • CTRL + A: 자동화 시작
  • CTRL + O: 자동화 중지

사용자 정의 단축키

다음을 위한 키를 설정할 수 있습니다:

  • 타입 1과 2 액션
  • 매크로(키 시퀀스)
  • 주기적 매크로

표시 옵션

패널 위치

Reborn 패널을 드래그할 수 있습니다:

  • 패널 헤더 클릭
  • 누른 채로 드래그
  • 원하는 위치에 놓기
  • 위치가 자동으로 저장됨

패널 불투명도

통계를 관리하면서 탐색을 방해하지 않도록 투명도를 조정하세요.

활동 로그

로그는 실시간으로 모든 수행된 액션을 표시합니다:

  • 시스템 활성화/비활성화
  • 포션 사용
  • 매크로 및 시퀀스 실행
  • 주기적 매크로 호출
  • 가능한 오류

설정 저장

모든 설정이 로컬에 자동 저장됩니다:

  • 선택한 테마
  • 인터페이스 언어
  • 활성화 임계값
  • 할당된 키
  • 매크로 구성
  • 패널 위치

브라우저를 닫은 후에도 세션 간에 유지됩니다.
