타입 1 자동 액션
구성 가능한 타이머를 기반으로 타입 1 액션(HP)을 자동으로 활성화합니다.

  • 백그라운드에서 작동

무료
시각적 테마
6가지 다른 테마로 인터페이스 외관을 사용자 정의하세요.
  • MMO Gold (기본값)
  • Cyber Blue, Neon Purple, Fire Red
  • 다크 모드 & 화이트 모드

무료

  • Polski, Русский, 中文, 日本語, 한국어, Filipino, Türkçe
  • 즉시 전환

프리미엄 기능 💎

❤️
PREMIUM
자동 트리거 1 매크로
구성 가능한 타이머를 기반으로 타입 1 액션(HP)의 자동 활성화.
  • 구성 가능한 트리거 1 타이머
  • 구성 가능한 단축키
  • 백그라운드에서 작동
💧
PREMIUM
자동 트리거 2 매크로
구성 가능한 타이머를 기반으로 타입 2 액션의 자동 사용.
  • 구성 가능한 트리거 2 타이머
  • 구성 가능한 단축키
  • 백그라운드에서 작동
⌨️
PREMIUM
키보드 단축키
사용자 정의 가능한 전역 단축키로 Reborn Assistant를 즉시 제어하세요.
  • CTRL+A: 자동화 시작
  • CTRL+O: 자동화 중지
🛡️
PREMIUM
시퀀스 로테이션
미리 정의된 시퀀스가 있는 자동 시퀀스 유지 시스템.
  • 시퀀스: F2 → 1-9 → 0 → F1
  • 구성 가능한 간격(분)
  • 키 사이 조정 가능한 지연
⚙️
PREMIUM
사용자 정의 매크로
자신만의 키 시퀀스로 최대 3개의 매크로를 만드세요.
  • 3개의 독립적인 매크로
  • 사용자 정의 시퀀스
  • 조정 가능한 반복 간격
🐉
PREMIUM
주기적 매크로
15초마다 주기적 매크로를 자동 호출 및 저장.
  • 주기적 매크로 자동 호출
  • 호출 후 자동 저장
  • 고정 15초 간격
