🛡️ 자동 시퀀스 로테이션

로테이션 시스템은 정기적인 간격으로 미리 정의된 키 시퀀스를 눌러 모든 시퀀스를 자동으로 활성 상태로 유지합니다.

키 시퀀스

로테이션은 항상 이 고정된 순서를 따릅니다:

F2 → 1 → 2 → 3 → 4 → 5 → 6 → 7 → 8 → 9 → 0 → F1

설정

사이클 간 간격
전체 시퀀스를 다시 시작하기 전 대기 시간. 기본값: 5분. 가장 짧은 시퀀스의 지속 시간에 따라 조정하세요.
키 사이 지연
시퀀스의 각 키 사이 대기 시간. 기본값: 1초. 서비스 속도에 따라 조정하세요(애니메이션, 쿨다운...).
💡 사용 예시

시나리오: 시퀀스가 5분 지속되고 키 1-8에 8개의 시퀀스가 있는 경우.

설정:

  • 간격: 5분
  • 지연: 1초
  • 확장 프로그램이 5분마다 F2, 1, 2, 3, 4, 5, 6, 7, 8, 9, 0, F1을 누릅니다
  • 총 13키, 각 키 사이 1초 = 사이클당 약 13초

⚙️ 사용자 정의 매크로

자신만의 키 시퀀스로 최대 3개의 독립적인 매크로를 만드세요. 반복 작업, 정기적인 콤보, 스킬 로테이션 자동화에 완벽합니다.

작동 원리

각 매크로는 다른 시스템과 독립적으로 정기적인 간격으로 키 시퀀스를 실행합니다.

설정

키 시퀀스
쉼표로 구분된 순서로 누를 키를 정의하세요. 예: 1,2,3,4 또는 q,w,e,r,f
반복 간격
시퀀스를 반복하기 전 대기 시간. 필요에 따라 설정하세요(초 또는 분).
키 사이 지연
시퀀스의 각 키 사이 대기 시간(일반적으로 0.5~2초).
💡 사용 예시

매크로 1 – 반복 자동화:

  • 시퀀스: 1,2,3,space
  • 간격: 10초
  • 사용: 루프에서 기본 공격 로테이션

매크로 2 – 스킬 콤보:

  • 시퀀스: q,w,e,r
  • 간격: 30초
  • 사용: 최적 DPS 로테이션

매크로 3 – 자동 지원:

  • 시퀀스: f,g,h
  • 간격: 15초
  • 사용: 그룹 시퀀스 또는 주기적 액션

🐉 주기적 매크로

이 시스템은 15초마다 자동으로 주기적 액션을 실행합니다. 정기적으로 활성화해야 하는 반복 작업에 이상적입니다.

작동 원리

시스템은 15초마다 이 시퀀스를 자동으로 실행합니다:

  1. 주기적 매크로 호출(구성 가능한 키, 기본값 §)
  2. 500ms 대기
  3. 주기적 매크로 자동 저장

설정

호출 키
주기적 매크로를 활성화하는 키. 기본값: §. 구성에 따라 변경하세요.
간격(고정)
시스템은 항상 고정된 15초 간격을 사용합니다. 구성 불가.
💡 사용 사례

일부 서비스에서는 아이템 수집, 임시 시퀀스 제공 또는 경험치 획득을 위해 주기적 매크로를 정기적으로 호출해야 합니다. 이 시스템은 이 과정을 완전히 자동화합니다.

⚠️ 중요

  • 설정된 키가 호출 키에 해당하는지 확인
  • 주기적 매크로는 각 호출 후 자동으로 저장됨
  • 다른 시스템(시퀀스, 매크로, 액션)과 병렬로 작동

최적화 팁

🎯 시스템 결합

모든 프리미엄 기능이 동시에 작동합니다. 다음이 가능합니다:

  • 자동 시퀀스 + 3개의 매크로 + 주기적 매크로를 동시에 활성화
  • 트리거 액션 1과 2는 항상 병렬로 작동
  • 각 시스템은 독립적인 타이머를 가짐

⚡ 성능

  • 활성화하는 시스템이 많을수록 확장 프로그램이 더 많은 리소스를 소비
  • 과도하게 빈번한 액션을 피하기 위해 간격 조정
  • 올바른 작동을 확인하기 위해 활동 로그 모니터링

🔑 보안

  • 프리미엄 라이선스가 실시간으로 검증됨
  • 연결이 끊어지면 프리미엄 기능이 비활성화됨
  • 모든 기능을 다시 활성화하려면 다시 로그인하세요
