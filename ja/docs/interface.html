🎨 インターフェース＆カスタマイズ

好みに合わせてReborn Assistantをカスタマイズ

ビジュアルテーマ

Reborn Assistantはインターフェースの外観をカスタマイズするための6つのテーマを提供:

MMO Gold
Cyber Blue
Neon Purple
Fire Red
Dark Mode
White Mode

テーマの変更

1. Rebornパネルを開く
2. 「⚙️ 設定」タブをクリック
3. ドロップダウンメニューでテーマを選択
4. 変更は即時に適用

言語の変更

1. Rebornパネルを開く
2. 「⚙️ 設定」をクリック
3. ドロップダウンメニューで言語を選択
4. インターフェース全体が即座に翻訳される

キーボードショートカット

Reborn Assistantには素早い操作のためのグローバルショートカットが含まれています:

システムショートカット

  • CTRL + A：自動化を開始
  • CTRL + O：自動化を停止

カスタマイズ可能なショートカット

以下のためにキーを設定できます:

  • タイプ1と2のアクション
  • マクロ（キーシーケンス）
  • 定期マクロ

表示オプション

パネルの位置

Rebornパネルはドラッグ可能です:

  1. パネルのヘッダーをクリック
  2. 押したまま移動
  3. 希望の場所で離す
  4. 位置は自動的に保存される

パネルの透明度

統計を管理しながらナビゲーションを妨げないよう透明度を調整。

アクティビティログ

ログはリアルタイムで全ての実行されたアクションを表示:

  • システムの有効化/無効化
  • ポーションの使用
  • マクロとシーケンスの実行
  • 定期マクロの呼び出し
  • エラーの可能性

設定の保存

全ての設定はローカルに自動保存されます:

  • 選択したテーマ
  • インターフェース言語
  • 起動しきい値
  • 割り当てられたキー
  • マクロ設定
  • パネルの位置

ブラウザを閉じた後もセッション間で保持されます。
