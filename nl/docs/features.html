PREMIUM

  • Werkt op de achtergrond

PREMIUM
Automatische activator macro 2
Automatisch gebruik van uw type 2-acties op basis van een configureerbare timer.
  • Configureerbare activator 2-timer
  • Configureerbare sneltoets
  • Werkt op de achtergrond
⌨️
PREMIUM
Sneltoetsen
Beheer Reborn Assistant direct met aanpasbare globale sneltoetsen.
  • CTRL+A: Start de automatisering
  • CTRL+O: Stop de automatisering
🛡️
PREMIUM
Reeksrotatie
Automatisch reeksonderhoudssysteem met een voorgedefinieerde reeks.
  • Reeks: F2 → 1-9 → 0 → F1
  • Configureerbaar interval (minuten)
  • Instelbare vertraging tussen toetsen
⚙️
PREMIUM
Aanpasbare Macro's
Maak tot 3 macro's met uw eigen toetsreeksen.
  • 3 onafhankelijke macro's
  • Aangepaste reeksen
  • Instelbare herhalingsintervallen
🐉
PREMIUM
Periodieke macro
Automatisch oproepen en opslaan van uw periodieke macro elke 15 seconden.
  • Automatisch oproepen van periodieke macro
  • Auto-opslaan na oproep
  • Vast interval van 15 seconden
