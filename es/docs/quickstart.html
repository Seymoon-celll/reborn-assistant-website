🚀 Inicio Rápido

Instala y configura Reborn Assistant en pocos minutos

Requisitos

🌐
Navegador compatible: Google Chrome, Microsoft Edge, Brave o cualquier navegador basado en Chromium
🔧
Cuenta de Google: Requerida solo para la autenticación Premium (opcional para la versión gratuita)
🎮
Sitio compatible: Compatible con sitios web estándar

Instalación

1
Visitar el Chrome Web Store

Ve a la página de Reborn Assistant en el Chrome Web Store y haz clic en «Añadir a Chrome».

💡 Compatible con Google Chrome, Microsoft Edge, Brave y cualquier navegador basado en Chromium.

2
Confirmar la instalación

Haz clic en «Añadir extensión» en la ventana de confirmación. La extensión se instala automáticamente.

3
Fijar la extensión

Haz clic en el ícono puzzle 🧩 en la barra de herramientas de tu navegador, luego fija Reborn Assistant para un acceso rápido.

4
Inicio de sesión (opcional para Premium)

• Haz clic en el ícono de Reborn en la barra de herramientas
• Para Premium: Inicia sesión con tu cuenta de Google
• Para Gratis: Úsalo directamente sin inicio de sesión

✅ ¡Instalación exitosa! El ícono de Reborn se vuelve verde cuando la extensión está activa. Ahora puedes configurar tus funciones.

Configuración inicial

Versión GRATUITA

Funciones disponibles sin inicio de sesión:

• Acción automática de tipo 1 (solo HP)
• 6 temas visuales
• Soporte de 15 idiomas

Configuración de la acción automática de tipo 1

1. Abre el panel de Reborn (clic en el ícono)
2. Ajusta el temporizador de la acción HP (por defecto: 2s)
3. La acción se activa automáticamente
4. No se requiere inicio de sesión

Versión PREMIUM 💎

Funciones adicionales (requiere inicio de sesión con Google):

• Macro activador 1 automático (temporizador configurable + atajo)
• Macro activador 2 automático (temporizador configurable + atajo)
• Atajos de teclado (CTRL+A / CTRL+O)
• Rotación automática de secuencias (F2 → 1-9 → 0 → F1)
• 3 macros personalizables con secuencias de teclas
• Sistema de macro periódica automático (llamada + almacenamiento cada 15s)

Configuración Premium

Secuencias automáticas:
• Activa «Rotación de Secuencias» en el panel
• Configura el intervalo entre ciclos (por defecto: 5 min)
• Ajusta el retraso entre cada tecla (por defecto: 1s)

Macros:
• Activa Macro 1, 2 o 3
• Define la secuencia de teclas (ej: 1,2,3,4)
• Configura el intervalo de repetición

Macro periódica:
• Activa el interruptor «Macro periódica»
• El sistema llama automáticamente a tu macro periódica cada 15s
• Almacenamiento automático tras la llamada

⚠️ Nota importante Las funciones Premium (Macros activadores 1 y 2, Secuencias automáticas, Macro periódica automática, 3 macros configurables) requieren una licencia Premium válida y un inicio de sesión de Google. Sin licencia, solo está disponible la macro básica.

Atajos de teclado

CTRL + A: Iniciar la automatización
CTRL + O: Detener la automatización
