🚀 Quick Start

Install and configure Reborn Assistant in a few minutes

Requirements

🌐
Compatible browser: Google Chrome, Microsoft Edge, Brave or any Chromium-based browser
🔧
Google account: Required only for Premium authentication (optional for free version)
🎮
Compatible site: Works with standard websites

Installation

1
Visit the Chrome Web Store

Go to the Reborn Assistant page in the Chrome Web Store and click «Add to Chrome».

💡 Compatible with Google Chrome, Microsoft Edge, Brave and any Chromium-based browser.

2
Confirm installation

Click «Add extension» in the confirmation window. The extension installs automatically.

3
Pin the extension

Click the puzzle icon 🧩 in your browser toolbar, then pin Reborn Assistant for quick access.

4
Login (optional for Premium)

• Click the Reborn icon in the toolbar
• For Premium: Log in with your Google account
• For Free: Use directly without login

✅ Installation successful! The Reborn icon turns green when the extension is active. You can now configure your features.

Initial configuration

FREE Version

Features available without login:

• Automatic action type 1 (HP only)
• 6 visual themes
• Support for 15 languages

Type 1 automatic action setup

1. Open the Reborn panel (click the icon)
2. Set the HP action timer (default: 2s)
3. The action triggers automatically
4. No login required

PREMIUM Version 💎

Additional features (requires Google login):

• Automatic trigger macro 1 (configurable timer + shortcut)
• Automatic trigger macro 2 (configurable timer + shortcut)
• Keyboard shortcuts (CTRL+A / CTRL+O)
• Automatic sequence rotation (F2 → 1-9 → 0 → F1)
• 3 customizable macros with key sequences
• Automatic periodic macro system (call + store every 15s)

Premium configuration

Automatic sequences:
• Enable «Sequence Rotation» in the panel
• Configure the interval between cycles (default: 5 min)
• Adjust the delay between each key (default: 1s)

Macros:
• Enable Macro 1, 2 or 3
• Define the key sequence (e.g. 1,2,3,4)
• Configure the repeat interval

Periodic macro:
• Enable the «Periodic macro» toggle
• The system automatically calls your periodic macro every 15s
• Auto-stored after the call

⚠️ Important note Premium features (Trigger macros 1 and 2, Automatic sequences, Automatic periodic macro, 3 configurable macros) require a valid Premium license and a Google login. Without a license, only the basic macro is accessible.

Keyboard shortcuts

CTRL + A: Start the automation
CTRL + O: Stop the automation
